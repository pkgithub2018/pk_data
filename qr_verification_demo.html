Phytosanitary Certificate Authentication Demo

How QR Code Verification Works

1 Certificate Is Created

When a phytosanitary certificate is approved, the system automatically generates a unique QR code containing verification data and a security hash.

2 QR Code Is Printed on Certificate

The QR code appears on the left side of the certificate with the label "Scan to Verify". Anyone can scan this code with their smartphone.

3 Scan to Verify Authenticity

Using any QR code scanner app, scan the QR code on the certificate. The verification page opens automatically showing certificate details and authenticity status.

4 View Certificate Information

The verification page displays: exporter/importer details, product information, issue date, authorized officer, and verification status with visual indicators.

Printable Results

Print verification results for records

Information Displayed on Verification

Certificate Details
  • Certificate number
  • Application number
  • Issue date and place
  • Certificate type (Export/Import)
Company Information
  • Exporter name and address
  • Importer name and address
  • Destination country
Product Details
  • Product/commodity name
  • Place of origin
  • Scientific name
Authorization
  • Authorized officer name
  • Officer position
  • Verification status

Verification Status Indicators

VERIFIED & AUTHENTIC

Certificate found in database and security hash matches. This certificate is authentic and valid.

CERTIFICATE FOUND

Certificate exists but no security hash was provided. Basic information verified but full authentication not completed.

VERIFICATION FAILED

Certificate not found, hash mismatch, or other error. This may indicate a fake or tampered certificate.
